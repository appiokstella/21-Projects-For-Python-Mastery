# Nunber Guesses Program (Updated Version)

This project is an improved version of the original Number Guessing Game. The initial program generated a random number within a user-defined range and allowed the player to keep guessing until the correct number was found, displaying the total number of guesses at the end.

## What's New

Compared to the original version, this project now includes:

- A difficulty setting that limits the number of guesses allowed
- A replay option at the end without restarting the program
- Tracking the best score across multiple rounds
